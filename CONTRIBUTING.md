All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository and clone your fork locally.
2. Create a focused branch for your change.
3. Make the change and test it locally.
4. Commit your work with a clear message and push the branch to your fork.
5. Open a pull request with a concise description of the change and its tests.

Please keep contributions focused, follow the existing file formats, and update
the documentation when behavior changes.

Please include a concise test description with each pull request.
